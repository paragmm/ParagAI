# ParagAI টিউটোরিয়াল ০৬: প্রতিদিন একটু একটু করে ট্রেনিং ও পেছনের জ্ঞান অক্ষুণ্ণ রাখার মাস্টার গাইড

আপনার মনে সবচেয়ে বড় যে প্রশ্নগুলো ছিল:
1. *"আমি প্রতিদিন একটু একটু করে ট্রেইনিং দিতে চাই। পরের দিন নতুন ডেটা দিলে কি আগের ফাইল মুছে যাবে নাকি যুক্ত হবে?"*
2. *"আগের দিনের জ্ঞান না ভুলে কি শুধু নতুন ডেটা ট্রেইন করা সম্ভব?"*
3. *"পরের দিনে নতুন কোনো শব্দ বা বর্ণ আসলে tokenizer.json ফাইলে কি ঘটবে?"*

এই গাইডটিতে এই প্রতিটি প্রশ্নের বৈজ্ঞানিক ও বাস্তবিক সমাধান সহজ ভাষায় ব্যাখ্যা করা হলো।

---

## ১. ক্যাটাস্ট্রফিক ফরগেটিং (Catastrophic Forgetting) সমস্যা কী?

মানুষের ব্রেইনের মতো এআই মডেলকে যদি ১ম দিন শুধু **"ইংরেজি গল্প"** শেখান এবং ২য় দিন ১ম দিনের কোনো ডেটা ছাড়া শুধু **"পাইথন কোড"** শেখান, তবে ব্যাকপ্রোপাগেশন (Backpropagation) এর কারণে নিউরাল নেটওয়ার্কের ওয়েটগুলো ২য় দিনের ডেটার সাথে মানিয়ে নিতে গিয়ে ১ম দিনের শেখা নিউরন প্যাটার্নগুলো ওভাররাইট (মুছে) ফেলে। একে বিজ্ঞানের ভাষায় বলে **Catastrophic Forgetting (বিপর্যয়মূলক বিস্মৃতি)**।

একই সাথে, আপনি যদি ২য় দিন `tokenizer.json` আবার নতুন করে তৈরি করেন, তবে টোকেনের আইডি উল্টাপাল্টা হয়ে যাবে (যেমন: ১ম দিন 'বাংলা' শব্দের আইডি ছিল ৪০, ২য় দিন তা হয়ে গেল ৯৫)। ফলে মডেলের মাথা সম্পূর্ণ নষ্ট হয়ে যাবে!

## ২. ParagAI-এর ৩টি স্থায়ী সমাধান

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       জ্ঞান না হারানোর ৩টি সোনালী নিয়ম                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ ১. টোকেনাইজার ফ্রিজ (Tokenizer Freeze):                                     │
│    IndicBPETokenizer একবার ২৫৬টি UTF-8 বাইটসহ তৈরি হলে তা আর কখনো বদলাবেন না।│
│    নতুন যেকোনো বর্ণ বা ইমোজি আসলে তা স্বয়ংক্রিয়ভাবে বাইট ফলব্যাকে সংরক্ষিত হবে!│
├─────────────────────────────────────────────────────────────────────────────┤
│ ২. রিপ্লে বাফার (Replay Buffer / Replay Mixing):                            │
│    পরের দিন যখন নতুন ডেটা ট্রেন করবেন, তখন পেছনের ডেটার ১৫-২০% অংশ নতুন ডেটার  │
│    সাথে মিশিয়ে দেবেন। এতে সম্পূর্ণ পুরোনো ফাইল ট্রেন করতে হবে না, অথচ মডেল পেছনের│
│    কোনো কথাই ভুলবে না!                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ ৩. চেকপয়েন্ট রিজিউম (Checkpoint Resume):                                   │
│    পরের দিন শুরু থেকে ট্রেন করবেন না, বরং আগের দিনের `best_model.pt` ফাইল থেকে  │
│    ট্রেনিং শুরু করবেন (কম লার্নিং রেট দিয়ে)।                                │
└─────────────────────────────────────────────────────────────────────────────┘
```

## ৩. প্রতিদিনের ট্রেনিংয়ের সহজ ধাপসমূহ

### ১ম দিন: গল্প ও মৌলিক জ্ঞান শেখানো
১. ডেটা রাখুন `data/raw/stories/day1_stories.txt` ফাইলে।
২. মডেল ট্রেইন করুন:
   ```bash
   python scripts/train.py \
     --data data/raw/stories/day1_stories.txt \
     --config configs/train_config.yaml \
     --max_iters 2000
   ```
৩. ফলাফল: তৈরি হবে `checkpoints/best_model.pt`।

---

### ২য় দিন: কথোপকথন বা চ্যাট শেখানো (পূর্বের গল্প না ভুলে)
পুরোনো সব ডেটা ট্রেন না করে শুধু নতুন কথোপকথনের সাথে পূর্বের ডেটার ১৫% মিশিয়ে নিন:
```bash
python -c "
with open('data/raw/stories/day1_stories.txt', 'r', encoding='utf-8') as f1, \
     open('data/raw/chat/conversations_sft.txt', 'r', encoding='utf-8') as f2, \
     open('data/processed/day2_train.txt', 'w', encoding='utf-8') as out:
    # নতুন ডেটা + পুরোনো ডেটার ১৫% রিপ্লে
    out.write(f2.read() + '\n\n' + f1.read()[:50000])
"
```

এখন আগের দিনের `checkpoints/best_model.pt` ফাইল লোড করে ট্রেনিং চালু করুন:
```bash
python scripts/train.py \
  --data data/processed/day2_train.txt \
  --resume checkpoints/best_model.pt \
  --learning_rate 0.0001 \
  --max_iters 1000
```
**ফলাফল:** মডেল এখন নতুন চ্যাটও শিখল, আবার আগের গল্পও সুন্দরভাবে মনে রাখল!

---

### ৩য় দিন: কোডিং ও অটোমেশন যুক্ত করা
একইভাবে আগের দিনের ডেটার কিছু অংশ নতুন কোডিং ডেটার সাথে মার্জ করে রিজিউম করুন:
```bash
python scripts/train.py \
  --data data/processed/day3_train.txt \
  --resume checkpoints/best_model.pt \
  --learning_rate 0.00008 \
  --max_iters 1000
```

## ৪. নতুন শব্দ বা বর্ণ যুক্ত হলে কী হবে?

ParagAI-এর নতুন **`IndicBPETokenizer`**-এ সব ২৫৬টি UTF-8 বাইট আগে থেকেই সংরক্ষিত থাকে:
- যদি পরের দিন এমন কোনো নতুন বাংলা যুক্তবর্ণ, হিন্দি শব্দ বা ইমোজি আসে যা ১ম দিনে ছিল না, তবুও টোকেনাইজার ক্র্যাশ করবে না।
- টোকেনাইজার সেই নতুন অক্ষরকে তার ভেতরের ৩টি বা ৪টি বাইটে রূপান্তর করে মডেলের কাছে পাঠিয়ে দেবে।
- ফলে `tokenizer.json` ফাইলের কোনো পরিবর্তন করার প্রয়োজন নেই এবং মডেলের কোনো ক্ষতি হবে না!

## ৫. ট্রেনিং শেষে পরীক্ষা করা

প্রতিদিনের ট্রেনিং শেষে ওলামা এবং স্ক্রিপ্ট দিয়ে টেস্ট করে নিন:
```bash
# ডায়াগনস্টিক পরীক্ষা
python scripts/doctor.py

# পারফরম্যান্স পরীক্ষা
python scripts/eval.py --checkpoint checkpoints/best_model.pt --tokenizer checkpoints/tokenizer.json --tasks multiling,tools,story

# ওলামাতে পাঠিয়ে টেস্ট
python scripts/export_hf.py --checkpoint checkpoints/best_model.pt --output_dir checkpoints/export_hf
python scripts/export_gguf.py --input_dir checkpoints/export_hf --tokenizer checkpoints/tokenizer.json --output checkpoints/paragai.gguf
ollama create paragai -f deploy/Modelfile
ollama run paragai:latest "Hello! একটি গল্প বলো।"
```
